# Musik/
Musik latar. File pertama (urut abjad) dipakai `reditor edit auto`; di Remotion isi `"musicPath": "music/<file>"`.
- Musik selalu di bawah VO (±18–22 LU lebih pelan) dan otomatis di-duck saat ada suara (sidechain).
- `bed_procedural_clean.mp3` = bed prosedural buatan sendiri (bebas lisensi), bisa dihapus.
- Hanya pakai musik yang kamu punya hak pakainya (lihat daftar sumber di `VFX/README.md`).

# raw-footage/
Taruh klip mentah di sini: `.mp4 .mov .mkv .webm .3gp` atau foto `.jpg .png .webp`.
- Nama file menentukan urutan default `reditor edit auto` (mis. `01_intro.mp4`, `02_produk.mp4`).
- Video HP vertikal/horizontal sama-sama bisa: editor otomatis crop ke 9:16 atau 16:9.
- File di folder ini **tidak di-commit** ke git (lihat `.gitignore`).
- Dari galeri HP: `cp /sdcard/DCIM/Camera/VID_*.mp4 ~/reditor-claude-nethunter/raw-footage/`

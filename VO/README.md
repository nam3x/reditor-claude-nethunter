# VO/
Voiceover final (`.mp3 .wav .m4a ...`). File pertama (urut abjad) yang dipakai.
- **Dipakai apa adanya**: tidak dipercepat/diperlambat, jeda tidak dipotong. Durasi video mengikuti VO.
- `reditor transcribe` → `transcript.json` (waktu per kata untuk takarir karaoke & sinkron potongan).
- Tempo ideal 2,7–3,2 kata/detik; atur lewat naskah, bukan dengan mengolah audio.
- Tidak ada TTS sebagai pengganti VO pengguna.
